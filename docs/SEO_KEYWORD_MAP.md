## Keyword Cannibalization Rules

1. **Homepage** targets broad brand + primary commercial terms ("web development company Sri Lanka")
2. **Service pages** target specific service + geographic variations ("WordPress development Sri Lanka")
3. **Blog articles** target informational queries only — never duplicate service page targets
4. No two pages should target the same primary keyword
5. Internal links use varied, descriptive anchor text to reinforce topical connections
